# DevDock Ultra

Интерактивная инженерная энциклопедия на русском языке: шесть связанных доменов — **HTML, CSS, JavaScript, SQL, Git, Computer Science**. Это не набор уроков, а система: каждая тема — «документ» с определением, ментальной моделью, примерами, типичными ошибками, упражнениями, вопросами для собеседования, экзаменационными и закрепляющими вопросами, а к модулям привязаны проекты с рубрикой оценки и самопроверкой.

Содержимое (проверяется валидатором): **180 тем, 42 проекта, 6 доменов**.

| Домен | Тем | Проектов |
|-------|-----|----------|
| HTML | 41 | 7 |
| CSS | 43 | 7 |
| JavaScript | 26 | 7 |
| SQL | 27 | 7 |
| Git | 21 | 7 |
| Computer Science | 22 | 7 |

## Запуск

Нужен Node.js 22.

```bash
npm install
npm run dev          # разработка, http://localhost:3000
npm run build        # production-сборка (статическая генерация всех тем и проектов)
npm run start        # запуск собранного приложения
```

Проверки качества:

```bash
npm run typecheck          # TypeScript
npm run lint               # ESLint
npm run validate:content   # стандарт контента: объём, примеры, упражнения, вопросы, ссылки
```

`validate:content` — главный страж качества: тема не проходит, если в ней меньше 900 слов, меньше трёх примеров кода, меньше двух упражнений, нет задачи-вызова, нет вопросов для собеседования трёх уровней, экзаменационных или закрепляющих вопросов, если у вопроса с вариантами пояснение короче 40 символов, если есть битая внутренняя ссылка или заглушка («скоро», `TODO`, lorem ipsum).

## Что внутри

- **Темы** — `/learn/<домен>/<тема>`: документ с оглавлением, прогрессом и связями с другими темами.
- **Практика, экзамен, собеседование** — `/practice/<домен>`, `/exam/<домен>`, `/interview/<домен>`: упражнения и вопросы из тем с проверкой ответов.
- **Проекты** — `/projects/<домен>/<проект>`: цель, сценарий, требования, технические подсказки, критерии приёмки, типичные ошибки, рубрика (сумма весов — 100) и эталонное решение с самопроверкой `check.mjs`.
- **Поиск** — `Ctrl/Cmd + K`: темы, понятия, упражнения, вопросы собеседований, примеры кода, проекты.
- **Песочница** — `/playground`: HTML/CSS/JS в изолированном `iframe`.
- **Карточки** — `/flashcards`: интервальное повторение; **Моё** — `/me`: прогресс, закладки, заметки (хранятся в браузере).

## Устройство

```
src/
  app/            маршруты Next.js (App Router)
  components/     интерфейс: документ темы, практика, поиск, песочница, карточки
  content/        контент: <домен>/domain.ts, <домен>/topics/*.ts, <домен>/projects/*.ts
    dsl.ts        конструкторы блоков (p, h, code, table, note, mcq, exercise, …)
    types.ts      модель контента: Domain → Module → Topic, Project
  lib/            поиск, подсветка кода (Shiki), разметка внутри строк
  store/          состояние ученика (Zustand, localStorage)
scripts/          validate-content.ts, check-sources.ts
DEVDOCK_PROGRESS.md   журнал работы и протокол продолжения
```

Новая тема — один файл `src/content/<домен>/topics/<slug>.ts` и строка в `topics/index.ts` (порядок в индексе — порядок изучения). Проект — файл в `projects/` и привязка в `domain.ts` (`module.project`).

Стек: Next.js 16 (App Router), TypeScript, Tailwind CSS v4, Framer Motion, Zustand, Shiki (на сервере), Fuse.js.

## Принцип достоверности

Числа, выводы команд и временные характеристики в темах получены **замерами** (Node.js 22.22.0, CPython 3.11, gcc 13.3, PostgreSQL 16, git 2.43, Chromium), а не из памяти; примеры кода запускались, решения проектов проходят свои самопроверки, а у каждой самопроверки есть набор «плохих» вариантов — реальных ошибок, которые она обязана заметить. Ссылки на источники — только канонические (спецификации, MDN, RFC, учебники); внешние адреса автоматически не проверяются.

Подробности и состояние по модулям — в [`DEVDOCK_PROGRESS.md`](./DEVDOCK_PROGRESS.md).
